Google Search Console 怎么验证网站？新站提交与收录全流程

2026-11-03 · 技术 SEO · 阅读约 6 分钟

网站上线只是第一步——搜索引擎不主动认识你，你要主动把站点递给它。Google Search Console（简称 GSC）是 Google 官方的站长平台，能提交站点、监控收录、看搜索展示与点击数据。本文记录本站从验证到提交收录的完整操作。

第一步：选择验证方式

打开 search.google.com/search-console，添加资源时有两个选项：

  • 网域（Domain）：覆盖所有子域，但需要 DNS 验证——GitHub Pages 不提供域名 DNS 控制权，选这个会卡住
  • 网址前缀（URL prefix）：只管这一个地址，支持多种验证方式，GitHub Pages 用户选这个

填入 https://你的用户名.github.io（注意带 https、末尾不带斜杠也可以，但要和实际地址一致）。

第二步：HTML 文件验证

网址前缀方式下推荐「HTML 文件」验证：

  1. 下载 GSC 提供的验证文件（形如 googlexxxxxxx.html）
  2. 把文件放到仓库根目录（和 index.html 同级）
  3. git push 后，浏览器访问 https://你的用户名.github.io/googlexxxxxxx.html 确认能打开
  4. 回到 GSC 点「验证」
验证失败排查：确认文件已 push 成功、GitHub Pages 已完成部署（Actions 页面看绿色对勾）、网址没有拼写错误。国内网络访问 GitHub Pages 不稳定时，换手机热点再试。

第三步：提交 sitemap.xml

sitemap 是给爬虫的「页面清单」。左侧菜单「站点地图（Sitemaps）」→ 输入 sitemap.xml → 提交。本站的 sitemap 内容：

<?xml version="1.0" encoding="UTF-8"?>
<urlset xmlns="http://www.sitemaps.org/schemas/sitemap/0.9">
  <url><loc>https://你的用户名.github.io/</loc></url>
  <url><loc>https://你的用户名.github.io/keyword-research.html</loc></url>
  <url><loc>https://你的用户名.github.io/tdk-guide.html</loc></url>
  <url><loc>https://你的用户名.github.io/gsc-setup.html</loc></url>
</urlset>

同时确认根目录有 robots.txt，并在其中声明了 sitemap 地址——这是爬虫协议的基本配置。

第四步：请求编入索引

GSC 最上面的搜索框是「网址检查（URL Inspection）」工具：输入任一页面 URL，先点「测试实际网址」确认可被编入索引，再点「请求编入索引」。这相当于对 Google 说「请尽快来看这个页面」，比被动等待快得多。四个页面逐个操作一遍。

提交之后看什么数据

  • 覆盖率报告：看有多少页面「已编入索引」，出现「已发现 - 尚未编入索引」说明爬虫来了但还没收录，属新站正常现象
  • 效果报告：1~2 周后开始有数据，能看到每个页面的展示次数、点击次数、平均排名和实际触发的搜索查询词
  • 新站收录周期：一般 1~7 天开始收录，权重完全建立需要数周

下一步

收录只是开始，真正的优化循环是：看效果报告里的查询词 → 对照当初的关键词布局 → 补内容、调 TDK（写法参考TDK 指南）→ 再观察数据变化。
